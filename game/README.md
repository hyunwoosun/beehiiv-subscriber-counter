# 토끼랑 곰돌이 대결

LG 스탠바이미 같은 터치스크린에서 둘이 함께 하는 미니게임 모음입니다. 파일 하나(`index.html`)로 동작하고 설치가 필요 없습니다.

화면 왼쪽 절반은 토끼, 오른쪽 절반은 곰돌이 차지예요. 가로 화면으로 세워 두고 나란히 서서 플레이하면 됩니다.

| 게임 | 방법 |
| --- | --- |
| 당근 줄다리기 | 내 쪽 화면을 최대한 빨리 연타해서 당근을 내 깃발까지 끌어오기 |
| 별 빨리 잡기 | 별이 뜨는 순간 먼저 터치. 먹구름이나 달에 속아 누르면 상대 점수. 3점 먼저 |
| 병아리 하키 | 손가락으로 내 캐릭터를 끌어 병아리를 상대 골대에 넣기. 5점 먼저 (멀티터치) |

- 메뉴의 "전체 화면" 버튼으로 브라우저 UI를 숨길 수 있어요.
- 게임 중 위쪽 집 버튼은 두 번 눌러야 메뉴로 나가요 (실수 방지).
- 전적은 그 기기의 브라우저에 저장됩니다.

## 스탠바이미에서 여는 법

1. 이 파일을 아무 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 올립니다.
2. 스탠바이미의 웹 브라우저에서 주소를 열고, 북마크해 두면 다음부터 바로 실행됩니다.
